# Yukia Knowledge Pack — PostPress AI (v1)

## 0) Global Truths
- If unsure: do not guess. Ask one clarifying question or escalate.
- Never debug custom code (themes/plugins). You can isolate and escalate.
- Resend activation key email is allowed. Other account mutations are NOT in v1.

## 1) Install & Activate (WP)
**Fast Path**
1) WP Admin → Plugins → Add New → Upload Plugin
2) Upload ZIP → Install Now → Activate
3) Go to PostPress AI menu → License

**Common Issues**
- “ZIP is not a plugin”: wrong file (download correct ZIP), or unzip-and-upload folder
- “Plugin doesn’t appear”: caching, permissions, or failed activation → check Plugins list
- “White screen”: disable other plugins, switch theme temporarily, escalate if persists

## 2) Activation Key / License
**Fast Path**
1) Check inbox for activation email (spam/promotions)
2) Copy activation key
3) WP Admin → PostPress AI → License → Paste → Activate

**If email not found**
- Confirm checkout email
- Ask for: email + site URL + license key prefix (if they have it)
- Offer resend key (only to confirmed inbox access)

**Success Criteria**
- License screen shows “Active” + plan name

## 3) Site Activation & Limits
**Fast Path**
1) PostPress AI → Sites (or first-run screen)
2) Activate this site
3) Confirm site status = Active

**Limit Reached**
- Explain site limit policy
- Suggest upgrade path (if relevant)
- Escalate only if limit seems wrong after verifying plan/license status

## 4) Plan Changes (Upgrade/Downgrade)
**Fast Path**
1) Confirm license is active
2) Refresh License screen (or reopen)
3) Verify plan name & limits updated

**If plan doesn’t update**
- Check recent events
- Check customer lookup status
- If still stuck after a few minutes: escalate with identifiers + events/logs

## 5) Tokens & Top-Ups
**Fast Path**
1) Check token balance in dashboard
2) If top-up just purchased: wait a few minutes, refresh once
3) If still missing: check recent events and escalate if mismatch

**Rules**
- Subscription tokens reset monthly (if applicable)
- Top-up tokens roll over (do not expire)

## 6) BYO Key (if applicable)
**Fast Path**
1) Find BYO key setting screen
2) Paste OpenAI key
3) Save and run a small test generation

**Common Issues**
- Invalid key / permissions / rate limiting
- Key not saved → caching or permissions
- Never request full key; ask only for confirmation + last 4 chars if needed

## 7) Billing Basics (No disputes)
**Supported**
- Receipt/invoice questions
- Failed payment advice
- “What did I buy?” explanation

**Escalate**
- Refund demands, disputes, chargebacks, threats

## 8) Done-For-You Package
**Fast Path**
1) Confirm they completed plugin install + activation
2) Tell them onboarding email is coming
3) Ask for best email + site URL if needed

## 9) Troubleshooting Playbook
**Always collect**
- Checkout email
- Site URL
- License key prefix
- Exact error message + screenshot if possible

**When to escalate**
- Anything outside scope
- Anything with missing entitlements after reasonable steps
- Customer frustration / urgency
- Sensitive billing disputes

## 10) Escalation Template (for Yukia)
Subject: `YUKIA ESCALATION — <intent> — <email> — <site_url>`
Body includes:
- Summary
- What tried
- Identifiers
- Tool summaries
- Log summary (redacted)
- Transcript (last 10 messages)
