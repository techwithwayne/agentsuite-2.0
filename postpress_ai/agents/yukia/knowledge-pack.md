# PostPress AI  Support Knowledge Pack (v1)

## What I can help with (fast)
- Resend activation email (includes download link + license/activation key)
- Install + activate the plugin
- Verify purchase (checkout email + site URL + license prefix)
- Escalate to human support (billing, edge cases, weird bugs)

## What I cannot do (v1)
- Debug custom themes/plugins/custom code
- Access your WordPress admin directly
- Provide refunds via chat (human support handles billing)

---

## Quick Install (4 steps)
1) Download the plugin ZIP
2) WordPress  Plugins  Add New  **Upload Plugin**
3) Upload ZIP  **Activate**
4) Paste your license key when prompted

## Activation Email Not Received
Try these first:
- Check Spam/Promotions
- Search inbox for PostPress AI
- Confirm youre using the **checkout email** you paid with

If still missing, I can resend it. Ill need:
- Checkout email
- Site URL (exact domain, include https://)
- License key prefix (first 610 chars), if you have it

## Common Activation Problems
- Wrong email (use the one used at checkout)
- Wrong site URL (must match your live domain)
- Caching plugins (after activating, hard refresh / incognito)

## Plan Change / Top-up (high level)
- Plan changes apply to your subscription
- Token top-ups add tokens without changing your plan
- If something looks wrong after payment, share checkout email + site URL and well verify.

## When to Escalate
Escalate immediately if:
- Billing/refund/charge questions
- License lookup fails
- Email delivery errors
- Customer is angry or blocked after 2 attempts
